# Репозиторий mcu_emulator

Репозиторий с эмулятором платы Arduino Nano на базе микроконтроллера Atmega328P

## Структура папок в проекте

```
mcu_emulator
├── cpu
│   ├── ...            Папка с файлами исходного кода эмуляции процессорного ядра
|
└── Makefile           Файл конфигурации сборки проекта
```

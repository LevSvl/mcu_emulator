# Репозиторий mcu_emulator

Репозиторий с эмулятором микроконтроллера Intel 8080

## Структура папок в проекте

```
mcu_emulator
├── etc
│   ├── ...            Папка со скриптами конфигурации проекта
|
├── hw
│   ├── ...            Папка с файлами исходного кода эмуляции аппаратного обеспечения
|
├── sw
│   ├── ...            Папка с файлами исходного кода программного обеспечения
|
├── tools
│   ├── ...            Папка с файлами исходного кода дополнительных утилит
|
└── Makefile           Файл конфигурации сборки проекта
```
